# ComPort Agent Skills

This folder contains specialized skills for maintaining and improving the ComPort / ComLab Reservation System.

## Available Skills

### comport-ai-assistant-workflow
Use when modifying ComPort GPT, AI tools, natural language commands, role-aware assistant behavior, or database-aware assistant responses.

### comport-role-access-guard
Use when modifying permissions, role-based UI, admin-only features, lab-staff-only features, or student restrictions.

### comport-prisma-api-validator
Use when modifying Prisma schema, backend routes, controllers, services, validation, or database migrations.

### comport-notification-ui-guardian
Use when modifying notifications, SSE, email notifications, notification badges, toasts, or real-time updates.

### comport-regression-test-runner
Use before deployment or after large changes to check login, reservations, schedules, dashboard pages, assistant actions, and role-based flows.

### comport-student-ux-polisher
Use when improving student-facing pages, reservation forms, schedule browsing, dashboard layout, mobile responsiveness, and loading states.

### comport-documentation-reviewer
Use when updating README, manuscript, API docs, setup guides, deployment notes, environment variable documentation, and user manuals.
