# ComPort Student UX Polisher Skill

## Purpose

Use this skill when improving the student experience in ComPort.

The student interface must be beginner-friendly, clean, and easy to understand without making the page look overcrowded or tutorial-heavy.

## Main Goals

1. Make the reservation flow obvious.
2. Make "Reserve Now" easy to find.
3. Keep the dashboard clean and professional.
4. Avoid oversized instructional cards.
5. Avoid duplicate CTA buttons.
6. Keep mobile layouts responsive.
7. Preserve existing ComPort design language.
8. Do not break notifications or assistant access.

## Preferred Student Navigation

Student sidebar should include:
1. Dashboard
2. Reserve Laboratory
3. My Reservations
4. ComPort Assistant
5. Profile

Do not remove ComPort Assistant from student navigation.

## Dashboard Guidelines

The student dashboard should include:
- clear title
- short helpful subtitle
- primary Reserve Now action
- My Reservations shortcut
- reservation status cards
- recent reservations
- compact status guide
- optional assistant help section

Avoid:
- too many large cards at the top
- repeated Reserve Now buttons
- tutorial-style layout that dominates the dashboard
- empty white space
- confusing labels such as "Laboratories" when the page is used for booking

## Recommended Dashboard Structure

1. Header or welcome area
2. Clean hero reservation card
3. Compact step guide inside the hero card
4. Reservation status cards
5. Recent Reservations
6. Compact Status Guide
7. ComPort Assistant help card

## Student-Friendly Wording

Use:
- Reserve Laboratory
- Reserve Now
- My Reservations
- Waiting for approval
- Ready to use
- Finished sessions
- Open for reservations

Avoid unnecessarily technical wording.

## Empty States

My Reservations empty state:
- Title: No reservations yet
- Text: Reserve an available computer laboratory schedule to get started.
- Button: Reserve Laboratory

Available schedules empty state:
- Title: No available schedules
- Text: Please check again later or ask laboratory staff for assistance.

## Mobile Rules

On mobile:
- No horizontal scrolling.
- Cards must stack cleanly.
- Buttons must be easy to tap.
- Notification UI must not break.
- Sidebar or menu must remain accessible.
- Text must remain readable.

## Before Finishing

Test:
1. Student dashboard.
2. Reserve Laboratory page.
3. My Reservations page.
4. ComPort Assistant route.
5. Notification popover.
6. Mobile layout.
7. Desktop layout.
8. No merge conflict markers.
